# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Работа ведётся строго по очереди: каждое включённое сообщество завершается до перехода к следующему. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Сообщества № 1 «Галина Петровна», № 2 «Валентина», № 3 «Баба Шура» и № 4 «Зоя — Кормлю и подсматриваю» подготовлены по текстовой части: у каждого есть канонический референс с публичным URL, настройка, контент-план на 7 дней, 28 постов и 44 промпта изображений.

Создание иллюстраций для сообществ № 1–4 завершено: проверено **176 из 176** изображений — по 44 для каждого сообщества. Файлы JPEG сохранены рядом с текстовыми промптами под тем же именем. Русская подпись на полупрозрачной подложке и бейдж «ЛИСТАЙ →» на первом фото карусели сгенерированы непосредственно внутри изображения — без скриптовой постобработки.

Переходный этап для № 1–4 завершён: по каждому сообществу проверены все 44 изображения (всего **176/176**). Для № 5 «Ирина — Жизнь в шоколаде» готовы три канон-референса, выбран фронтальный Ref-A с публичным URL в `сообщества/05_Ирина/канон/CANON_URL.txt`, настройка, контент-план, 28 постов (каждый от 1000 символов) и 44 промпта. Созданы и проверены **44 из 44** JPG для № 5: все семь дней завершены. Все изображения проверены на соответствие парам TXT/JPG и имеют формат JPEG 1024×1024; русские надписи и бейджи сгенерированы непосредственно в кадрах. Канон-референсы созданы инструментом Arena, не Midjourney. Для № 6 «Бабушка Нина — По-нашему» создан и опубликован канон из трёх PNG 1024×1024, выбран Ref-A с прямым публичным URL; готовы настройка, контент-план, 28 постов (минимум 1385 символов) и 44 промпта. Созданы и визуально проверены **20 из 44** JPG (JPEG 1024×1024): день 2 полностью готов, день 1 готов кроме фото поста 2, в день 3 не хватает одного кадра карусели, в день 4 готовы первые два фото. Два прежних брака (рамка и посторонние этикетки) успешно заменены. Один новый кадр карусели дня 3 удалён из-за повторённого заголовка и будет перегенерирован; остальные изображения будут подготовлены до перехода к № 7. Сообщество № 8 «Катя — Беременна в 38» исключено и не меняется.
