# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Работа ведётся строго по очереди: каждое включённое сообщество завершается до перехода к следующему. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Сообщества № 1 «Галина Петровна», № 2 «Валентина», № 3 «Баба Шура» и № 4 «Зоя — Кормлю и подсматриваю» подготовлены по текстовой части: у каждого есть канонический референс с публичным URL, настройка, контент-план на 7 дней, 28 постов и 44 промпта изображений.

Начато создание самих иллюстраций для постов этих четырёх сообществ: готово **60 из 176** изображений: все 44 для № 1 «Галина Петровна»; у № 2 «Валентина» полностью готовы дни 1–2, а в дне 3 — посты 1–2 и фото 1–2 поста 3. Файлы JPEG сохраняются рядом с текстовыми промптами под тем же именем. Русская подпись на полупрозрачной подложке и бейдж «ЛИСТАЙ →» на первом фото карусели генерируются непосредственно в изображении по промпту — без скриптовой постобработки.

Сначала нужно завершить изображения для сообществ № 1–4, затем продолжать очередь с № 5. Канон-референсы созданы инструментом Arena, не Midjourney; выбранные изображения опубликованы в публичном репозитории. Сообщество № 8 «Катя — Беременна в 38» исключено и не меняется.
