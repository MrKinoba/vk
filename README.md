# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Работа ведётся строго по очереди: каждое включённое сообщество завершается до перехода к следующему. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Сообщества № 1 «Галина Петровна», № 2 «Валентина» и № 3 «Баба Шура» полностью подготовлены: для каждого есть канонический референс с публичным URL, настройка, контент-план на 7 дней, 28 постов и 44 промпта изображений.

Сообщество № 4 «Зоя — Кормлю и подсматриваю» полностью подготовлено: выбран Ref-A, шаг 0 завершён, публичный URL записан в `сообщества/04_Зоя/канон/CANON_URL.txt`; готовы настройка, контент-план на 7 дней, 28 постов и 44 промпта изображений. Длина постов — от 1301 до 1511 символов; у каждого поста есть открытый вопрос, все ссылки на промпты проверены. Канон-референсы созданы инструментом Arena (не Midjourney); выбранный Ref-A опубликован в публичном репозитории по разрешению пользователя. Изображения постов используют этот URL с `--cw 0`.

Сообщества № 1–4 подготовлены полностью. № 8 «Катя — Беременна в 38» исключено и не меняется.

Полные рабочие ограничения и порядок подготовки перечислены в [ТЗ.md](ТЗ.md).
