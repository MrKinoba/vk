# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Работа ведётся строго по очереди: каждое включённое сообщество завершается до перехода к следующему. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Сообщества № 1 «Галина Петровна», № 2 «Валентина», № 3 «Баба Шура» и № 4 «Зоя — Кормлю и подсматриваю» подготовлены по текстовой части: у каждого есть канонический референс с публичным URL, настройка, контент-план на 7 дней, 28 постов и 44 промпта изображений.

Создание иллюстраций для сообществ № 1–4 завершено: проверено **176 из 176** изображений — по 44 для каждого сообщества. Файлы JPEG сохранены рядом с текстовыми промптами под тем же именем. Русская подпись на полупрозрачной подложке и бейдж «ЛИСТАЙ →» на первом фото карусели сгенерированы непосредственно внутри изображения — без скриптовой постобработки.

Переходный этап для № 1–4 завершён: по каждому сообществу проверены все 44 изображения (всего **176/176**). Начата подготовка № 5 «Ирина — Жизнь в шоколаде»: созданы три канон-референса, выбран фронтальный Ref-A, его публичный URL записан в `сообщества/05_Ирина/канон/CANON_URL.txt`; готовы настройка и контент-план. Следующий этап для № 5 — написать и проверить 28 постов (не менее 1000 символов каждый), подготовить промпты и сгенерировать 44 изображения. Канон-референсы созданы инструментом Arena, не Midjourney. Сообщество № 8 «Катя — Беременна в 38» исключено и не меняется.

Полные рабочие ограничения и порядок подготовки перечислены в [ТЗ.md](ТЗ.md).
