# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Подготовлен каркас сообщества № 1 — «Галина Петровна — Угощаю с душой». Созданы три локальных черновых референса `Ref-A`, `Ref-B`, `Ref-C`; пользователем выбран `Ref-A`. Файлы находятся в `сообщества/01_Галина-Петровна/канон/`. Они созданы инструментом Arena, не Midjourney.

Работа остановлена перед следующим этапом: исходный репозиторий закрытый, а в `канон/CANON_URL.txt` нужен реальный публичный URL выбранного изображения для `--cref`. Файл пока пуст — локальный путь не считается публичной ссылкой. Хотя пользователь разрешил публичное GitHub-хранилище, в этой сессии файлы публикуются только в рабочей ветке закрытого репозитория; отдельное публичное хранилище не создаётся. Настройка, контент-план и посты не создаются до появления URL, чтобы не подставлять фиктивный канон.

## Как продолжить

1. Разместить `ref-a.png` во внешнем публичном хранилище и предоставить прямой URL изображения.
2. Записать ссылку в `сообщества/01_Галина-Петровна/канон/CANON_URL.txt` (одна строка, без пояснений).
3. Только после этого заполнять настройку, контент-план, 28 постов и связанные промпты картинок.

Полные рабочие ограничения и порядок подготовки перечислены в [ТЗ.md](ТЗ.md).
