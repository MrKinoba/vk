# Сеть VK-сообществ: женские дневники и еда

Рабочая структура для подготовки контента 20 сообществ. Сообщество № 8 «Катя — Беременна в 38» намеренно исключено и не редактируется.

## Текущий статус

Подготовлен каркас сообщества № 1 — «Галина Петровна — Угощаю с душой». Созданы три референса `Ref-A`, `Ref-B`, `Ref-C`; выбран `Ref-A`. Файлы находятся в `сообщества/01_Галина-Петровна/канон/`. Изображения созданы инструментом Arena, не Midjourney; по разрешению пользователя выбранный референс размещён в публичном репозитории, а прямой URL записан в `сообщества/01_Галина-Петровна/канон/CANON_URL.txt`.

Сообщества № 1 «Галина Петровна», № 2 «Валентина» и № 3 «Баба Шура» полностью подготовлены: настройка, контент-план, по 28 полных постов и по 44 промпта изображений. Тексты проверены на объём, открытый вопрос в конце и наличие связанных файлов картинок. Для сообщества № 4 «Зоя» подготовлены Ref-A/B/C и выбран Ref-A; его публичный URL ещё не записан, поэтому настройка и посты не создаются до завершения шага 0. Канон-референсы созданы инструментом Arena (не Midjourney); выбранные изображения № 1–3 опубликованы в публичном репозитории и записаны в `CANON_URL.txt`. Сообщество № 8 «Катя — Беременна в 38» исключено и не меняется.
